# Backend client helpers

- `supabase.ts` creates the typed Supabase browser client.
- `supabase.types.ts` defines the database types used by the client layer.
- `authService.ts` wraps email/password auth.
- `marketplaceService.ts` wraps operators, live marketplace journeys, posting jobs and claiming jobs.
- `matchingService.ts` scores possible empty-leg matches.
